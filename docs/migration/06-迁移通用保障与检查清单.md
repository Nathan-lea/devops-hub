# 迁移通用保障与检查清单

> 适用于所有迁移类型。各 SOP 文档中的检查清单均引用本文档。

---

## 一、迁移前检查清单（通用）

> 迁移启动前必须逐项确认，全部打勾方可进入迁移执行。

### 1.1 通用检查项
- [ ] 迁移评估报告通过评审（兼容性、数据量、影响面、停机窗口）
- [ ] 回滚预案已编写并经评审
- [ ] 迁移窗口已申请，窗口内禁止其他变更
- [ ] 源端完整备份已完成且验证可恢复
- [ ] 目标环境已就绪（资源、网络、组件）
- [ ] `scripts/migration/pre_migration_check.sh` 全部通过
- [ ] 通知相关业务方迁移时间窗口
- [ ] 值班人员已就位（双人）
- [ ] 监控大盘已添加源端+目标端对比视图
- [ ] DNS TTL 已提前 24h 调至 60s（涉及 DNS 切换时）

### 1.2 数据库迁移附加项
- [ ] 源端无长事务、无大 DDL 正在执行
- [ ] 源端 binlog 已开启且格式为 ROW（MySQL）
- [ ] 增量同步工具（DM/CDC）已部署并测试连通
- [ ] 数据校验工具已就绪
- [ ] 目标端字符集、时区与源端一致
- [ ] 目标端参数已调优（连接数、缓冲池等）
- [ ] 序列/自增列同步方案已确认（PG 场景）

### 1.3 K8s 迁移附加项
- [ ] 目标集群版本与源集群兼容（差不超过 1 个小版本）
- [ ] 目标集群已安装 Ingress Controller、Cert Manager
- [ ] 镜像仓库可达（或镜像已推送至目标云仓库）
- [ ] Velero 已安装且备份存储可访问
- [ ] StorageClass 已映射（NFS -> EBS/EFS）
- [ ] NetworkPolicy 已适配目标集群网络模型

### 1.4 Web 迁移附加项
- [ ] Nginx 配置已通过 `nginx -t` 语法检查
- [ ] SSL 证书已同步且剩余有效期 > 30 天
- [ ] 静态资源 rsync 增量同步已追平
- [ ] upstream 后端地址已更新（跨云时）
- [ ] 系统调优参数已对齐（ulimit / sysctl）

## 二、数据一致性校验方法

| 校验维度 | 方法 | 工具 | 适用场景 |
|----------|------|------|----------|
| 行数对比 | 源端 vs 目标端 count(*) | `migration_data_verify.sh` | 所有 DB 迁移 |
| 校验和 | SUM(CRC32(*)) 对比 | `migration_data_verify.sh` | 中小表 |
| 抽样对比 | 随机取 N 条记录逐字段对比 | sync-diff-inspector | 大表抽样 |
| 全量对比 | 逐行对比 | sync-diff-inspector | 小表全量 |
| 文件对比 | 文件数 + 大小 + rsync dry-run | `migration_data_verify.sh` | Web 静态资源 |
| 业务校验 | 关键业务流程端到端验证 | 人工/自动化测试 | 切换后必做 |

```bash
# 数据校验执行（迁移后必做）
bash scripts/migration/migration_data_verify.sh \
  --source <源IP> --target <目标IP> \
  --type mysql|pg|file --db <库名>

# 返回码：0 = 通过/仅警告 | 1 = 存在失败项，禁止切换
```

## 三、回滚预案模板

> 每次迁移前填写此模板，作为回滚操作依据。

```
## [迁移项目名] 回滚预案

### 回滚触发条件
- [ ] 切换后 5 分钟内错误率 > 1%
- [ ] 切换后核心业务功能不可用
- [ ] 数据校验发现不一致
- [ ] 业务方紧急叫停

### 回滚步骤
1. [ ] DNS/配置中心/路由 切回源端（< 5min）
2. [ ] 确认源端服务正常（curl 健康检查）
3. [ ] 确认源端数据完整性（增量同步是否中断数据）
4. [ ] 通知业务方回滚完成
5. [ ] 记录回滚原因，安排复盘

### 回滚验证
- [ ] 业务功能正常
- [ ] 监控指标恢复正常
- [ ] 无数据丢失

### 回滚后行动
- 分析失败根因
- 修复问题后重新规划迁移窗口
- 更新迁移方案文档
```

> 回滚辅助脚本：`bash scripts/migration/migration_rollback.sh --type <dns|sync|check> --action rollback`

## 四、迁移监控与告警

迁移期间需临时加强监控，以下规则在迁移完成后移除：

```yaml
# 迁移期间临时告警规则（迁移完成后移除）
groups:
  - name: migration_alerts
    rules:
      # 迁移期间源端/目标端服务不可用
      - alert: MigrationServiceDown
        expr: up{host=~"migr.*"} == 0
        for: 30s
        labels:
          severity: critical
        annotations:
          summary: "迁移目标 {{ $labels.host }} 服务不可用"

      # 迁移期间增量同步延迟
      - alert: MigrationSyncLag
        expr: dm_syncer_binlog_lag > 10
        for: 1m
        labels:
          severity: major
        annotations:
          summary: "DM 增量同步延迟 {{ $value }}s"

      # 迁移期间错误率飙升
      - alert: MigrationErrorRate
        expr: rate(nginx_requests_total{status=~"5.."}[1m]) > 1
        for: 1m
        labels:
          severity: major
        annotations:
          summary: "迁移期间 5xx 错误率飙升"
```

## 五、实施检查清单（按迁移类型）

### 5.1 通用清单
- [ ] 迁移评估报告完成（兼容性/数据量/影响面/窗口）
- [ ] 回滚预案编写并评审
- [ ] `pre_migration_check.sh` 迁移前执行通过
- [ ] `migration_data_verify.sh` 迁移后执行通过
- [ ] 灰度切换完成（10%->50%->100%）
- [ ] 观察 7 天无异常后下线源端

### 5.2 数据库迁移清单
- [ ] MySQL->TiDB：DM 部署 + 全量增量同步 + sync-diff 校验
- [ ] PG->TiDB：Schema 转换 + CSV 导入 + 序列同步 + 双写追平
- [ ] 跨云迁移：网络打通 + DM/CDC 同步 + DNS 切换
- [ ] 增量同步延迟 < 1s 后方切换
- [ ] 切换后行数 + 校验和对比一致

### 5.3 K8s 迁移清单
- [ ] 目标集群就绪 + 组件安装
- [ ] 无状态应用 GitOps 重建部署
- [ ] 有状态应用 Velero 备份恢复
- [ ] StorageClass 映射正确
- [ ] Ingress/DNS 灰度切换完成
- [ ] 源集群资源保留 7 天后清理

### 5.4 Web 迁移清单
- [ ] Nginx 配置同步 + nginx -t 通过
- [ ] SSL 证书同步 + 有效期 > 30 天
- [ ] 静态资源 rsync 增量追平
- [ ] DNS 加权灰度切换
- [ ] 错误率/响应时间监控正常
