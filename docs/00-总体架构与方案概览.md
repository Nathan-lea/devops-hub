# 服务器运维系统总体方案概览

## 一、项目背景与目标

### 1.1 现状描述
- **服务器规模**：约 100 台 Linux 主机
- **发行版**：Debian、Ubuntu、CentOS（含 Stream/RHEL 系）
- **主机来源**：公有云（阿里云/腾讯云/AWS 等）、私有云（OpenStack/vSphere 等）、物理机
- **核心中间件**：MySQL、TiDB、Redis、Web 服务器（Nginx/Apache）
- **容器编排**：Kubernetes 集群（生产/测试多套）

### 1.2 建设目标
| 维度 | 目标 |
|------|------|
| 可观测性 | 全量主机 + 中间件 + K8s 指标、日志、链路三维度覆盖 |
| 自动化 | 配置/部署/巡检/备份 80%+ 自动化 |
| 稳定性 | 核心系统 SLA 99.9%，故障 MTTR < 30 分钟 |
| 安全合规 | 资产台账清晰，漏洞/基线/权限可审计 |
| **入侵检测** | **异常连接、网络攻击实时检测与自动响应** |
| 成本可控 | 资源利用率可视化，避免过度预留 |

### 1.3 设计原则
1. **统一管控**：一套平台纳管多云异构主机，避免烟囱式工具
2. **分层解耦**：采集层 → 存储层 → 展示层 → 告警层，各层可独立演进
3. **基础设施即代码**：Ansible + Git 管理所有配置，变更可追溯
4. **主动预防**：容量预测 + 趋势告警，从被动救火转向主动运营
5. **安全左移**：基线扫描、密钥轮换、最小权限贯穿全流程
6. **纵深防御**：从网络边界到主机内核，多层检测与响应

## 二、技术选型总览

| 能力域 | 选型方案 | 说明 |
|--------|----------|------|
| 监控采集 | **Prometheus + node_exporter + 各类 exporter** | 时序数据库，生态丰富，适配 K8s |
| 监控展示 | **Grafana** | 多数据源统一看板 |
| 日志收集 | **Loki + Promtail**（轻量）或 **ELK**（重日志场景） | 与 Prometheus 体系同构，降低运维成本 |
| 链路追踪 | **Tempo + OpenTelemetry** | 与 Grafana 全家桶整合 |
| 配置管理 | **Ansible** | Agentless，适配异构主机 |
| 资产台账 | **CMDB（自研轻量 + NetBox）** | 自动发现 + 人工补录 |
| 告警通知 | **Alertmanager + 企微/钉钉/飞书机器人** | 分级路由，告警收敛 |
| 自动化任务 | **Ansible AWX / Semaphore** | Web 化编排 |
| 备份 | **Velero（K8s）+ xtrabackup（MySQL）+ rclone** | 多层次备份 |
| 安全合规 | **kube-bench + Lynis + Trivy** | 基线 + 漏洞扫描 |
| **主机入侵检测(HIDS)** | **Wazuh** | FIM + rootkit检测 + 主动响应 + 日志关联分析 |
| **网络入侵检测(NIDS)** | **Suricata** | ET规则集 + 自定义规则 + 协议异常检测 |
| **暴力破解防护** | **fail2ban** | SSH/Nginx/MySQL/Redis + 递归封禁 |
| **威胁情报** | **AbuseIPDB + AlienVault OTX** | 恶意IP/域名自动拉取与匹配 |
| **容器安全** | **Falco + Trivy** | 运行时安全 + 镜像扫描 |
| **Web防护(WAF)** | **ModSecurity + OWASP CRS** | SQL注入/XSS/RCE防护 |
| IaC 仓库 | **GitLab/Gitea + CI/CD** | 版本化配置 |

### 2.1 架构分层图（文字版）

```
┌─────────────────────────────────────────────────────────────┐
│                     展示与告警层                              │
│   Grafana看板 │ Alertmanager │ 告警机器人(企微/钉钉/飞书)     │
│   Wazuh安全看板 │ Grafana安全看板                             │
├─────────────────────────────────────────────────────────────┤
│                     安全分析与响应层                          │
│   日志关联分析 │ 威胁情报关联 │ 自动封禁 │ 应急响应SOP        │
│   入侵检测告警 │ 异常连接告警 │ 容器安全告警                  │
├─────────────────────────────────────────────────────────────┤
│                     入侵检测层 (IDS)                          │
│   Wazuh(HIDS) │ Suricata(NIDS) │ auditd │ fail2ban          │
│   反向Shell检测 │ rootkit检测 │ 持久化后门检测 │ 暴力破解防护  │
│   异常连接检测 │ 威胁情报匹配 │ 容器行为检测(Falco)           │
├─────────────────────────────────────────────────────────────┤
│                     存储与处理层                              │
│   Prometheus │ Loki │ Tempo │ CMDB │ 任务调度引擎            │
│   VictoriaMetrics(长期存储) │ MinIO(对象存储)               │
├─────────────────────────────────────────────────────────────┤
│                     采集层（Agent）                           │
│ node_exporter│mysqld_exporter│redis_exporter│tidb监控         │
│ promtail │ kube-state-metrics │ blackbox_exporter            │
│ Wazuh Agent │ Suricata │ Falco │ auditd                     │
├─────────────────────────────────────────────────────────────┤
│                     网络防护层                                │
│   防火墙(iptables/nftables) │ 安全组 │ WAF(ModSecurity)      │
│   DDoS防护 │ 网络分段 │ 入站/出站管控 │ 端口最小化            │
├─────────────────────────────────────────────────────────────┤
│                     被纳管主机层                              │
│  公有云 │ 私有云 │ 物理机 │ K8s 集群 │ MySQL/TiDB/Redis      │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 管控拓扑

- **管控节点（跳板机/Bastion）**：1~2 台，部署 Ansible、AWX、CMDB
- **监控中心**：2~3 台（Prometheus 主备 + Grafana + Loki）
- **安全中心**：1~2 台（Wazuh Server + Suricata）
- **被管主机**：通过 SSH（密码/密钥）或 Agent 接入
