## 二、主机安全加固基线

### 2.1 系统加固清单（适用 Debian/Ubuntu/CentOS）

| 类别 | 加固项 | 实施方式 |
|------|--------|----------|
| **账号口令** | 密码长度≥12，复杂度要求 | /etc/security/pwquality.conf |
| | 密码过期 90 天 | chage / login.defs |
| | 禁用空密码用户 | passwd -l |
| | 锁定闲置账号（30天未登录） | 脚本定期检查 |
| **SSH** | 禁止 root 直接登录 | PermitRootLogin no |
| | 禁止密码登录，仅密钥 | PasswordAuthentication no |
| | 修改默认端口 | Port 22222 |
| | 限制登录 IP | AllowUsers / Match |
| | 登录失败锁定 | fail2ban |
| | 空闲超时断开 | ClientAliveInterval 300 |
| **文件权限** | /etc/passwd 644 | chmod |
| | /etc/shadow 000/640 | chmod |
| | 关键目录不可写 | audit + 修复 |
| | SUID/SGID 定期审计 | find / -perm -4000 |
| **内核** | 禁用不需要的内核模块 | /etc/modprobe.d/ |
| | 开启 SYN flood 防护 | sysctl net.ipv4.tcp_syncookies |
| | 禁用 IP 转发（非路由器） | net.ipv4.ip_forward=0 |
| **服务** | 禁用非必要服务 | systemctl disable |
| | 关闭多余端口 | ss -tlnp 审计 |
| **审计** | 开启 auditd | /etc/audit/auditd.conf |
| | 记录 sudo/特权命令 | audit 规则 |
| | 日志远程转发 | rsyslog -> Loki |

### 2.2 Ansible 基线加固 Playbook
详见 `playbooks/06-security-audit.yml`，涵盖：
- 密码策略
- SSH 加固
- 文件权限
- 内核参数
- 服务禁用
- auditd 配置

## 三、漏洞管理

### 3.1 漏洞扫描体系
| 扫描类型 | 工具 | 频率 | 范围 |
|----------|------|------|------|
| 主机漏洞 | **Lynis** + **oval-probe** | 每周 | 全部主机 |
| 容器镜像 | **Trivy** | 每次构建/每日 | Harbor 镜像 |
| K8s 基线 | **kube-bench** | 每月 | K8s 节点 |
| 依赖漏洞 | **Trivy fs** | CI 集成 | 代码仓库 |
| 端口扫描 | **nmap** | 每月 | 全网段 |

### 3.2 漏洞处理 SLA
| 等级 | CVSS | 响应时限 | 修复时限 |
|------|------|----------|----------|
| 紧急 | 9.0~10.0 | 1 小时 | 24 小时 |
| 高危 | 7.0~8.9 | 4 小时 | 7 天 |
| 中危 | 4.0~6.9 | 1 天 | 30 天 |
| 低危 | 0.1~3.9 | 3 天 | 季度修复 |

### 3.3 补丁管理流程
```
扫描 -> 评估 -> 申请窗口 -> 测试环境验证 -> 生产灰度 -> 全量修复 -> 复扫确认
```

CentOS/RedHat 补丁：
```bash
# 安全补丁（不影响业务）
yum update --security -y

# Ubuntu/Debian
apt update && unattended-upgrade --dry-run -v
```

## 四、密钥与证书管理

### 4.1 SSH 密钥
- 统一使用 ED25519 算法
- 私钥加密存储（passphrase）
- Ansible Vault 管理分发
- 每 6 个月轮换一次
- 离职/调岗即时吊销

### 4.2 TLS 证书
| 证书类型 | 管理方式 | 有效期 | 续期 |
|----------|----------|--------|------|
| 对外业务 | Let's Encrypt + acme.sh | 90 天 | 自动续期 |
| 内部服务 | 自建 CA（cfssl/step-ca） | 1 年 | 半自动 |
| K8s 组件 | kubeadm / cert-manager | 1 年 | 定期检查 |
| 数据库 | 自建 CA | 1 年 | 提前 30 天告警 |

### 4.3 证书过期监控
```yaml
# Prometheus blackbox_exporter 证书检测
- alert: TlsCertExpiringSoon
  expr: probe_ssl_earliest_cert_expiry - time() < 86400 * 30
  for: 1h
  labels:
    severity: warning
  annotations:
    summary: "证书将在 30 天内过期: {{ $labels.instance }}"
```

## 五、权限与审计

### 5.1 权限模型
```
┌──────────────────────────────────────┐
│  运维人员 (ops) - sudo 约束            │
│  -> 主机运维、中间件运维               │
│  -> 禁止 rm -rf /、DROP DATABASE      │
├──────────────────────────────────────┤
│  研发 (dev) - 跳板机受限访问           │
│  -> 只读日志、指定 namespace          │
│  -> 禁止生产数据访问                  │
├──────────────────────────────────────┤
│  DBA - 数据库专用账号                  │
│  -> 通过堡垒机操作                     │
│  -> 全程录像审计                       │
├──────────────────────────────────────┤
│  自动化 - 专用 service account         │
│  -> 最小权限                          │
│  -> 定期轮换 token                    │
└──────────────────────────────────────┘
```

### 5.2 sudo 审计
```bash
# /etc/sudoers.d/ops 约束
ops ALL=(ALL) NOPASSWD: /usr/bin/systemctl restart nginx, \
                        /usr/bin/systemctl status *, \
                        /usr/sbin/xtrabackup *
# 禁止 shell
Defaults:ops !visiblepw, requiretty
```

### 5.3 操作审计（auditd 关键规则）
```bash
# 监控关键文件修改
-w /etc/passwd -p wa -k identity
-w /etc/sudoers -p wa -k sudoers
-w /etc/ssh/sshd_config -p wa -k ssh_config

# 监控特权命令执行
-w /usr/bin/sudo -p x -k privilege
-w /usr/bin/su -p x -k privilege

# 监控 cron 修改
-w /etc/crontab -p wa -k cron
-w /etc/cron.d/ -p wa -k cron
```

### 5.4 堡垒机（Jumpserver）
- 所有生产主机登录必须经过堡垒机
- 全程操作录像
- 敏感命令拦截（rm -rf, DROP DATABASE）
- 账号生命周期管理
- 定期权限复核

## 六、网络安全

### 6.1 网络分区
```
┌─────────────┐    ┌──────────────┐    ┌─────────────┐
│  公网区     │    │  应用区       │    │  数据区      │
│ (LB/Ingress)│--->│ (Web/App/K8s)│--->│ (DB/Redis)  │
│             │    │              │    │             │
└─────────────┘    └──────────────┘    └─────────────┘
     ↓                  ↓                   ↓
  WAF/DDoS        安全组/网络策略        仅内部访问
```

### 6.2 安全组规则原则
- **默认拒绝**：所有入站默认拒绝
- **最小放行**：仅放行业务必需端口
- **按需开放**：临时端口限时关闭
- **日志审计**：安全组变更记录

### 6.3 防火墙（主机层）
```bash
# nftables/iptables 基线（示例）
# 放行 SSH(22222)、监控端口(9100/9104/9121)
# 限制来源 IP
iptables -A INPUT -p tcp --dport 22222 -s 10.0.0.0/8 -j ACCEPT
iptables -A INPUT -p tcp --dport 9100 -s 10.0.0.10 -j ACCEPT
iptables -A INPUT -j DROP
```

## 九、入侵检测与网络安全（详见 11-入侵检测与网络安全方案）

### 9.1 概述
本节为安全合规体系中的主动检测与响应部分，完整方案详见
**[11-入侵检测与网络安全方案](11-入侵检测与网络安全方案.md)**。

### 9.2 能力覆盖
| 能力 | 工具 | 说明 |
|------|------|------|
| 主机入侵检测 (HIDS) | Wazuh | FIM + rootkit检测 + 主动响应 + 日志关联 |
| 网络入侵检测 (NIDS) | Suricata | ET规则集 + 自定义规则 + 协议异常 |
| 暴力破解防护 | fail2ban | SSH/Nginx/MySQL/Redis + 递归封禁 |
| 异常连接检测 | 自定义脚本 + auditd | 出站白名单 + 进程关联 + 连接突增 |
| 威胁情报 | AbuseIPDB + OTX | 恶意IP/域名自动拉取与匹配 |
| 容器安全 | Falco + Trivy | 运行时行为检测 + 镜像漏洞扫描 |
| Web防护 | ModSecurity + OWASP CRS | SQL注入/XSS/RCE/目录遍历防护 |
| 自动封禁 | fail2ban + Wazuh主动响应 | 检测到攻击自动iptables/nftables封禁 |
| 主机隔离 | 自定义脚本 + Ansible | 确认入侵后立即隔离 + K8s cordon |

### 9.3 安全事件应急 SOP
| 事件类型 | 检测方式 | 响应动作 |
|----------|----------|----------|
| 确认入侵 | Wazuh + Suricata + 脚本 | 隔离主机 + 取证 + 从备份恢复 |
| 勒索软件 | auditd + 文件监控 | 立即隔离 + 快照 + 从备份恢复 |
| 挖矿木马 | 威胁情报 + 进程检测 | 隔离网络 + kill进程 + 清除持久化 |
| 暴力破解 | fail2ban | 自动封禁 + 检查是否成功入侵 |
| 反向Shell | 脚本 + Suricata | 隔离主机 + 取证 + 排查 |

> 完整应急 SOP 详见 [08-告警与应急方案](08-告警与应急方案.md) 和
> [11-入侵检测与网络安全方案](11-入侵检测与网络安全方案.md)
